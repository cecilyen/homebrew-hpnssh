# Homebrew HPN-SSH Tap

Main conclusion: this tap packages HPN-SSH 18.9.0 for macOS arm64 on Apple
Silicon, with separate OpenSSL 3 and AWS-LC bottles.

## Formulae

- `hpnssh`: builds HPN-SSH against Homebrew `openssl@3`.
- `hpnssh-awslc`: builds HPN-SSH against Homebrew `aws-lc` and links suffixed
  commands such as `hpnssh-awslc` and `hpnsshd-awslc`.

Both formulae build from the official `rapier1/hpn-ssh` `hpn-18.9.0` tag,
apply the macOS default-port patch to use port `22`, enable Pluggable
Authentication Modules (PAM) and Basic Security Module (BSM) audit support, and
compile for `arm64` with `-O3 -flto -g0 -mcpu=apple-m2`.

## GitHub Release Upload

The bottles generated by this workspace are intended for a GitHub release named:

```sh
hpnssh-18.9.0-macos26-arm64
```

The formulae use the bottle root URL:

```sh
https://github.com/yencc/homebrew-hpnssh/releases/download/hpnssh-18.9.0-macos26-arm64
```

If you publish under a different GitHub owner, repository, or release tag,
update the bottle `root_url` in both formulae before pushing the tap.
